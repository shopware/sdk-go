# Support

## Questions

Use the Shopware community channels for usage questions:

- Developer documentation: https://developer.shopware.com/docs/guides/plugins/apps/
- Forum: https://forum.shopware.com/

## Bugs

Open a GitHub issue with:

- SDK version or commit SHA.
- Go version.
- Framework or integration used.
- Minimal reproduction.
- Expected behavior.
- Actual behavior, including logs or error output.

## Security Issues

Do not open a public issue for security vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Commercial Or Product Questions

Use normal Shopware support and account channels for product, partner, or commercial questions. This repository is for the Go SDK itself.
